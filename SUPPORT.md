# Support

Núcleo AI is an actively evolving alpha maintained through this GitHub repository.

## Where to ask

- **Reproducible bug:** open an Issue using the Bug Report template.
- **Feature idea:** open an Issue using the Feature Request template.
- **Build or installation question:** include the app version, Android version, and the relevant GitHub Actions run link where possible.
- **Security concern:** follow [SECURITY.md](SECURITY.md); do not post vulnerability details publicly.
- **Copyright or permission request:** contact the repository owner through the linked GitHub profile.

## Before opening an Issue

Search existing Issues for duplicates. Include the smallest useful reproduction and remove all personal data, private source, API keys, OAuth tokens, and signing secrets. Do not upload a complete private repository or an APK that contains credentials.

Support is best-effort. There is no guaranteed response time, and roadmap ideas are not commitments to implement a feature.
