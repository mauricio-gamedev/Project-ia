# Contributing

Thank you for taking an interest in Núcleo AI.

## Project status and contribution policy

Núcleo AI is a source-visible, proprietary alpha, not an open-source project. The repository's public visibility does not grant permission to reuse or redistribute its original code. Unsolicited code contributions are not currently accepted unless the maintainer has explicitly invited the work and agreed in writing on the applicable terms.

You are welcome to open an Issue to discuss a reproducible bug, a usability concern, a proposed feature, or a documentation correction. Please do not publish confidential information, API keys, OAuth tokens, signing credentials, private source code, or security vulnerabilities in an Issue.

## Bug reports

Use the Bug Report template and include:
- the app version and Android version;
- concise reproduction steps;
- expected and actual behavior;
- sanitized logs or screenshots, if useful;
- whether the issue reproduces consistently.

Remove personal data, credentials, private repository names, and tokens before attaching diagnostic material.

## Feature proposals

Use the Feature Request template. Explain the problem being solved, the expected user benefit, constraints, possible security/privacy impact, and how success could be verified.

## Quality expectations

The project prioritizes correctness, traceable evidence, least privilege, explicit consent before data transfer, and clear separation between implemented behavior and roadmap proposals. Do not describe a feature as complete unless its code, tests, and validation support that claim.

## Licensing

The repository is covered by the proprietary notice in [LICENSE](LICENSE). Do not submit code or assets unless you own them or have permission to submit them and the maintainer has explicitly agreed to the contribution terms. Third-party code must retain its applicable notices and license obligations.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of opening a public Issue.
